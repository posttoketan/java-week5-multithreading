# Week 5 - Java Multithreading and Concurrency

## Internship Project
Engineer - Java Development

## Overview
This repository contains Java programs developed during Week 5 of the Java Development internship. It focuses on multithreading, concurrency, synchronization, and thread management.

## Topics Covered
- Thread Class
- Runnable Interface
- Lambda Expressions with Threads
- Synchronization
- Inter-Thread Communication
- wait() and notify()
- Thread Pool
- ExecutorService
- Concurrent Task Processing

## Programs

1. 01-ThreadClass - Creating threads using the Thread class.
2. 02-RunnableInterface - Creating threads using Runnable.
3. 03-LambdaThread - Creating threads using lambda expressions.
4. 04-Synchronization - Managing shared resources safely.
5. 05-InterThreadCommunication - Communication between threads using wait() and notify().
6. 06-ThreadPool - Managing multiple tasks using ExecutorService.
7. 07-ConcurrencyApplication - Complete concurrency application.

## Technologies Used
- Java
- Multithreading
- Runnable Interface
- ExecutorService
- Synchronization

## Learning Outcomes
Learned how to create and manage multiple threads, execute tasks concurrently, prevent race conditions using synchronization, and manage threads using ExecutorService.
